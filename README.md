# AI Air Quality Assistant

A project for monitoring, analyzing, and explaining air-quality information with AI.

## Project Structure

- `frontend/` - User interface and client-side application code.
- `backend/` - Server-side APIs and application services.
- `data/` - Datasets, processed measurements, and generated data.
- `documents/` - Project documentation and reference material.
- `ai/` - AI models, prompts, experiments, and inference logic.
- `screenshots/` - Screenshots for documentation and presentations.
- `ppt/` - Presentation files and related assets.
